## 📚 Conteúdos Estudados

Este projeto de estudos abrange uma variedade de tópicos em Python, incluindo:

- **Fundamentos da Linguagem**: Variáveis, tipos de dados, operadores.

- **Estruturas Condicionais**: `if`, `else`, `elif`, e condicionais em uma linha (`if_one_line.py`).

- **Laços de Repetição**: `for` (`for_loop.py`) e `while` (`while.py`, `while_loops.py`).

- **Funções**: Definição e uso de funções (`funcoes.py`).

- **Estruturas de Dados**:
  - **Listas e Arrays**: Manipulação de listas e uso do módulo `array` (`array.py`).
  - **Dicionários**: Criação, manipulação, iteração e organização de dicionários (`dicionario.py`, `dictionary_loop.py`, `dictionary_organization.py`).
  - **Conjuntos (Sets)**: Operações com conjuntos (`set.py`, `set_funcoes.py`, `set_string.py`).

- **Programação Orientada a Objetos (POO)**:
  - **Classes e Objetos**: Definição de classes e criação de objetos (`main.py`, `main_funcionarios.py`).
  - **Herança**: Herança simples (`exercicio_heranca.py`, `main_heranca.py`, `main_hernanca_1.py`) e herança múltipla (`heranca_multipla.py`).
  - **Polimorfismo**: Demonstração de polimorfismo (`polymorphism.py`).
  - **Agregação**: Relações entre objetos onde um objeto contém outro (`agregacao.py`, `livros_agregacao.py`).
  - **Classes Aninhadas**: Exemplo de classes dentro de outras classes (`nested_aninhadas.py`).
  - **Uso de ****`super()`**: Chamada de métodos da classe pai (`usando_super.py`).

- **Funções Lambda**: Uso de funções anônimas (`lambda.py`, `lambda_map_tabuada.py`).

- **Manipulação de Strings**: Exemplo de uso do método `split()` (`split.py`).

## ▶️ Como executar

Para explorar os exemplos deste repositório, siga os passos abaixo:

1. **Clone o repositório**:

   ```bash
   git clone https://github.com/seu-usuario/python_-dev.git # Substitua 'seu-usuario' pelo seu nome de usuário do GitHub
   ```

1. **Acesse a pasta do projeto**:

   ```bash
   cd python_-dev
   ```

1. **Execute um arquivo Python**: Escolha qualquer arquivo `.py` e execute-o usando o interpretador Python.

   ```bash
   python nome_do_arquivo.py
   ```

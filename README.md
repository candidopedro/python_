## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/python-estudos.git
```

Acesse a pasta:

```bash
cd python-estudos
```

Execute um arquivo Python:

```bash
python nome_do_arquivo.py
```
